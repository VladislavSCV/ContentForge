Ниже — сценарий YouTube Shorts. Придумай короткие тексты для анимированной инфографики поверх видео.
Это крупные надписи на экране телефона: максимально коротко, без воды, только из фактов сценария и поста.

layout — раскладка первого экрана. «claim», если пост или позиция автора СПОРИТ с общепринятым («не нужна», «вопреки», «на самом деле», «ошибка думать»): тогда myth — что обычно думают (до 8 слов), truth — как на самом деле, тезис поста (до 8 слов), оба из фактов поста. Иначе «number»: myth и truth пустые строки. Спорный тезис важнее цифры: если поста хватает на спор, бери «claim».
flow — цепочка «причина → следствие» из поста для схемы на экране: 3–4 узла по 1–3 слова, последний узел — чем всё кончилось («30 подов», «600 соединений», «база падает»). Только факты поста, без выдуманных цифр. Нет цепочки — пустой список. flow_icons — по одной иконке на узел из списка: server, db, user, queue, cloud, code, clock, money, shield, bolt, box (не подходит ничего — box).
hook_big — ГЛАВНАЯ ЦИФРА из поста (1–3 слова: «35%», «47 минут», «$38 000», «40 → 26 узлов»). Цифра бьёт сильнее слов — бери её, если в посте есть хоть какое-то число. Только если чисел нет совсем — самый резкий факт в 2–3 словах. Заполняй всегда, даже при «claim».
hook_small — пояснение к цифре (до 6 слов): что это за величина.
problem_before — в чём ошибка (до 5 слов), problem_after — к чему она привела (до 5 слов).
steps — 2–3 шага решения технической проблемы, каждый 2–4 слова, ТОЛЬКО в повелительном наклонении («Собери в два этапа», «Выбери distroless», «Убери .git из образа»). Не «Применили…» и не «Использование…». Не про подписку на канал.
code — 3–7 строк настоящего кода, конфига или команды, которые показывают суть решения: фрагмент Dockerfile, YAML, bash-команда, SQL-запрос, PromQL. Зритель смотрит на него на телефоне, поэтому строки короткие (до 38 символов), без комментариев. Бери код из поста; если в посте его нет — напиши минимальный пример по сути поста, ТОЛЬКО если уверен, что он корректен. Не уверен — оставь пустую строку. code_language — язык кода строчными буквами.
stock_queries — 3 коротких запроса НА АНГЛИЙСКОМ для стокового видео-фона. Фон должен быть ТЁМНЫМ и техническим:
серверные, стойки, дата-центры ночью, код на экране, терминал, провода, платы («dark server room», «code on screen»,
«data center night», «circuit board macro»). Нельзя: города, природу, людей, офисы, светлые и дневные сцены —
на них текст не читается.
